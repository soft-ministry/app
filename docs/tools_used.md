## Current Policy

- Prefer permissive licenses: MIT, Apache 2.0, BSD.
- Avoid AGPL/GPL libraries in application dependencies unless there is an explicit commercial/legal review.
- Generate dependency notices before each commercial release:
  - Backend: `mvn project-info-reports:dependencies`
  - Frontend: `npm install && npm run build` plus a license report tool such as `license-checker-rseidelsohn` or equivalent, after its own license is reviewed.
- Keep this file updated whenever a new direct dependency is added.
